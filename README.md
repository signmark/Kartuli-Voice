# Kartuli-Voice MVP

AI-ассистент с озвучкой грузинского языка.

## Стек

- **Бот**: Python 3.11+ / python-telegram-bot
- **Озвучка**: Edge TTS
- **Перевод**: встроенный словарь, затем Gemini 3.8 Flash для остальных фраз
- **Избранное**: SQLite в `data/favorites.sqlite3`, аудио в `data/audio/`

## Быстрый старт

```bash
# Нужны Git, Python 3.11+ и доступ в интернет для установки пакетов
git clone https://github.com/signmark/Kartuli-Voice.git
cd Kartuli-Voice
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt

# Настройка окружения
cp .env.example .env
chmod 600 .env
# Открыть .env в текстовом редакторе и вписать TELEGRAM_BOT_TOKEN от @BotFather.
# GEMINI_API_KEY нужен только для фраз вне встроенного словаря.

# Запуск
python -m kartuli.bot
```

Бот общается с Telegram через сеть;
без настоящего `TELEGRAM_BOT_TOKEN` он не запустится. Проверка без токена:
`python -m unittest discover -q`. Никогда не добавляйте `.env` в Git.

Фразы из словаря переводятся без сети и без ключа Gemini. Для остальных фраз
бот обращается к Gemini с таймаутом 15 секунд. Если ключ отсутствует или сервис
недоступен, бот показывает ошибку и не строит транскрипцию и кнопку озвучки.
Ответ Gemini принимается только тогда, когда все его буквы грузинские.
Ключи не следует записывать в репозиторий или журналы.

## Использование

- `/start` показывает приветствие, `/help` — короткую инструкцию.
- Неизвестная команда получает подсказку вместо молчания.
- Русская фраза возвращает грузинский перевод и подсказки по произношению;
  кнопка «▶️ Озвучить» создаёт аудио через Edge TTS.
- «⭐ В избранное» сохраняет фразу и mp3 после выбора одной из шести категорий.
  Команда `/favorites` или кнопка «📂 Избранное» открывает категории и карточки.
  В карточке звук воспроизводится из сохранённого файла; удаление идёт отдельной
  кнопкой. У каждого пользователя Telegram свой список.
- При недоступности перевода или озвучки бот сообщает об ошибке и продолжает работать.
- Кнопка «📂 Избранное» доступна также после `/start` и `/help`. Во время
  перевода бот показывает «печатает», во время озвучки — «записывает голос»;
  признак обновляется до завершения операции. Ошибки перевода и озвучки
  показываются понятным сообщением без служебных деталей.

Путь к базе можно задать через `FAVORITES_DB_PATH` в `.env`. По умолчанию бот
сам создаёт `data/`, базу SQLite и каталог `data/audio/`; они исключены из Git.
Если удалить базу, `/favorites` покажет пустой список. Если mp3 пропал,
кнопка воспроизведения сообщит об этом и не вызовет озвучку повторно.
При пересоздании удалённой базы оставшиеся без карточек mp3 очищаются.
